# 프론트엔드와 복지자원 후보 조회

공통 메뉴와 복지자원 추천 화면을 HTML·CSS·JavaScript로 구성했다. Node.js 및 별도 패키지 설치는 필요 없다.

## 실행

프로젝트 최상위 폴더에서 실행한다.

```powershell
python backend/server.py
```

브라우저에서 <http://127.0.0.1:5175>를 연다. 첫 화면은 빈 대시보드이고, **복지자원 추천** 메뉴에서 구현한 화면을 볼 수 있다. 종료는 터미널에서 `Ctrl+C`.
화면과 추천 API를 같은 서버가 제공한다. 기존 `python -m http.server` 명령이나 HTML 파일 직접 열기로는 추천 API가 동작하지 않는다.

## 파일

- `index.html`: 공통 메뉴, 빈 페이지, 추천 화면, 상세 대화상자.
- `styles.css`: 초록 계열 디자인과 모바일·태블릿 레이아웃.
- `app.js`: 주소 해시 기반 페이지 이동, 조건 조회, 상세 보기, 선택 목록과 JSON 내려받기.
- `../backend/server.py`: 로컬 정적 화면 및 추천 API 서버.
- `../ai/welfare_agent/recommender.py`: 입력 검증, 후보 필터, 일치 근거와 결과 생성.
- `../ai/welfare_agent/welfare_resources.json`: 공식 안내를 확인해 편집한 실제 자원 6개. 가상 자원 파일을 대체한다.

## 현재 범위

- 대시보드·분석·프로그램 기획·평가·예산은 제목과 빈 화면만 제공한다.
- 추천 페이지는 지역·연령·지원 목적에 맞는 **공식 안내 자원 후보**를 필터링한다. 추천 점수·위험 단계·자격 판정을 생성하지 않는다.
- 재조회하면 이전 선택은 초기화된다. 탭 이동 시에는 선택을 유지하며, 새로고침하면 초기화된다. 조회 중에는 조건 변경을 막고 실패 시 재시도 버튼을 제공한다.
- 선택 목록은 로컬 JSON으로 내려받는다. `is_demo: false`, `risk_assessment: null`을 포함하며 실제 기획 Agent에 전송하지 않는다. 최종 연동 계약은 담당자와 별도로 합의해야 한다.
- 상세 정보에서 공식 출처·페이지 확인일·수정일·신청 방법을 확인한다. 운영 상태는 기관 확인 필요로 표시하며 현재 모집 중이라고 확정하지 않는다.
- 60대 이상과 만 65세 이상처럼 집단과 서비스의 연령이 일부만 겹치면 별도 표시한다. 연령 기준 미명시도 구분한다.

입출력 형식과 후속 작업은 [복지 추천 연결 안내](../docs/welfare_agent.md)를 참고한다.
