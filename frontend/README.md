# 프론트엔드와 복지자원 후보 조회

공통 메뉴와 복지자원 추천 화면을 HTML·CSS·JavaScript로 구성했다. Node.js 및 별도 패키지 설치는 필요 없다.

## Tavily + Gemini 설정

프로젝트 루트 `.env`에 TAVILY_API_KEY, GEMINI_API_KEY, GEMINI_MODEL=gemini-3.5-flash-lite를 설정한다. 기존 파일을 덮어쓰지 말고 키를 Git·채팅에 올리지 않는다. Tavily Free 플랜과 Google AI Studio 무료 등급을 유지한다. 앱이 결제 등급을 확인하는 것은 아니다.

정상 요청당 Tavily 기본 검색 최대 2회와 Gemini 판단 1회를 호출한다. 같은 검색 결과는 서버 메모리에서 5분간 재사용할 수 있다. 검색·모델 한도 초과 시 중단하며 자동 재시도·유료 전환·저장 자료 대체는 하지 않는다.

## 실행

프로젝트 최상위 폴더에서 실행한다.

```powershell
python backend/server.py
```

브라우저에서 <http://127.0.0.1:5175>를 연다. 첫 화면은 빈 대시보드이고, **복지자원 추천** 메뉴에서 구현한 화면을 볼 수 있다. 종료는 터미널에서 `Ctrl+C`.
화면과 추천 API를 같은 서버가 제공한다. 기존 `python -m http.server` 명령이나 HTML 파일 직접 열기로는 추천 API가 동작하지 않는다.

## 파일

- `index.html`: 공통 메뉴, 빈 페이지, 추천 화면, 상세 대화상자.
- `styles.css`: 초록 계열 디자인과 모바일·태블릿 레이아웃.
- `app.js`: 주소 해시 기반 페이지 이동, 조건 조회, 상세 보기, 선택 목록과 JSON 내려받기.
- `../backend/server.py`: 로컬 정적 화면 및 추천 API 서버.
- `../ai/welfare_agent/live_agent.py`: Tavily 공식 사이트 검색과 Gemini 추천 판단, 검색 출처 대조, 무료 지원 모델 제한.
- `../ai/welfare_agent/recommender.py`: 입력 검증과 저장 자료 테스트용 필터.
- `../ai/welfare_agent/welfare_resources.json`: 공식 안내를 확인해 편집한 실제 자원 6개. 가상 자원 파일을 대체한다.

## 현재 범위

- 대시보드·분석·프로그램 기획·평가·예산은 제목과 빈 화면만 제공한다.
- 실시간 검색·AI 추천이 기본이다. 버튼 클릭 시 외부 검색 후 LLM이 분석 결과와 자원을 대조한다. 페이지 진입·새로고침에는 유료 호출이 없다. 위험 단계와 개인 자격은 재판정하지 않는다.
- 저장 자료 조회는 테스트용이며 6개 자원을 조회한다. 실시간 실패 시 자동 대체하지 않는다.
- 재조회하면 이전 선택은 초기화된다. 탭 이동 시에는 선택을 유지하며, 새로고침하면 초기화된다. 조회 중에는 조건 변경을 막고 실패 시 재시도 버튼을 제공한다.
- 위험도 입력은 상단 접이식 영역에 초안 JSON으로 직접 입력한다. 예시 입력 채우기 버튼도 제공한다. 실제 위험도 자동 수신은 연결 전이다.
- 실시간 모드에서 지원 필요 체크박스는 선택적인 참고 정보다. 저장 자료 테스트 모드에서만 기존 필터 규칙을 적용한다. 지역·연령을 바꾸면 이전 집단의 지원 필요 선택은 해제한다.
- 결과에는 AI 추천 요약, 추천 이유, 출처, 관측 제한과 추가 확인 질문을 표시한다. 보류·불완전 위험도와 일반 조회를 구분한다.
- ‘다음 대응 검토’에 기존 자원 연계·예방 및 신규 기획·추가 확인 사항을 표시한다. 후보가 있어도 예방 기획을 함께 검토하며, 정상 조회의 후보 0개와 조회 실패를 구분한다. 조회 전·조회 중에는 이전 대응 경로를 표시하지 않는다. 경로 표시는 추가 API 호출을 만들지 않는다.
- 선택 목록은 위험도·관측 제한·규칙 버전·지원 필요·주의사항을 포함해 로컬 JSON으로 내려받는다. 실제 기획 Agent에 전송하지 않는다. `is_demo: false`는 공식 자원 목록을 뜻하며, 예시 위험도일 때는 `has_example_context: true`와 위험도의 `is_example: true`로 별도 구분한다. 최종 연동 계약은 담당자와 별도로 합의해야 한다.
- 상세 정보에서 공식 출처·페이지 확인일·수정일·신청 방법을 확인한다. 운영 상태는 기관 확인 필요로 표시하며 현재 모집 중이라고 확정하지 않는다.
- 60대 이상과 만 65세 이상처럼 집단과 서비스의 연령이 일부만 겹치면 별도 표시한다. 연령 기준 미명시도 구분한다.

입출력 형식과 후속 작업은 [복지 추천 연결 안내](../docs/welfare_agent.md)를 참고한다.

키 설정 여부는 인증 성공이나 무료 등급 검증을 뜻하지 않는다. 실제 검색·추천 품질과 모집 여부는 별도 확인해야 한다.

추천 카드는 지원 분야(경제·생활 안정/기타 포함)와 고립 예방 연관성(AI 분류)을 구분한다. 추천 이유·연관성·신청 전 확인 사항을 나눠 표시하고, 위험도 미연결은 일반 문장으로 안내한다. 출처는 검색일과 자료 기준 연도를 분리하며 과거 자료·미확인 자료에 주의 표시를 한다. 상세 화면에서 연도 근거 인용을 볼 수 있다. 이는 검색 발췌문 대조이며 현행 자격·운영 검증은 아니다.

Gemini 503 등 서버 오류는 30초 후 직접 재시도할 수 있도록 버튼에 대기 시간을 표시한다. 자동 호출은 없다. 같은 조건으로 5분 이내에 다시 시도하면 Tavily 검색 결과를 재사용하고 Gemini만 새로 호출한다. 서버를 재시작하면 보관된 검색 결과도 사라진다.

자료 연도는 적용 기준과 발행·게시를 구분한다. 후보 제외 사유의 건수도 화면에 표시한다. 초기 실호출 결과와 미검증 조건은 [추천 검증 기록](../docs/welfare_agent_validation.md)을 참고한다.

지역 공식 사이트를 먼저 검색하고 상세 안내 단서가 부족할 때만 중앙 공식 자료를 한 번 보완한다. 정상 빈 검색을 보완하는 동작이며, 한도·통신 오류를 자동 재시도하는 동작은 아니다. 상세 단서·자료 형식으로 검토 순서를 정하지만 원문 정확도를 보증하지는 않는다.

화면의 대응 경로 표시·재조회 초기화 검사는 개발 환경에 Node.js가 있을 때 `node --test tests/test_welfare_frontend.cjs`로 실행한다. 테스트는 외부 API 없이 동작하며 일반 화면 실행에는 Node.js가 필요 없다.
