# 위험도 설계 전 모델 입력 검토

## 검토 범위와 결과

2026-10-11 현재 `risk_features.csv`는 2025년 7~12월×2지역×6연령의 **72행·92열**이다.
점수·등급·개인 라벨은 없고, 이 문서는 위험도 개발 전 탐색 후보를 정리한다.
특징을 삭제하거나 결측을 대체하거나 학습·표준화하지 않는다.

| 사용 목적 | 열 수 | 처리 |
| --- | ---: | --- |
| 식별키 | 3 | 월·지역·연령. 결합·보고 및 시간 순서에 사용 |
| 입력 검토 후보 | 3 | 활동량 변화 후보. 방향·가중치·유효성은 위험도 브랜치에서 검토 |
| 맥락 | 73 | 규모·소비 구성·관측 품질·지역 공통값 설명용 |
| 초기 점수 입력 제외 | 13 | 중복 출처 지표, 미분류 상수, 금융·기타서비스·유흥 지표. 원본에는 보존 |

분류는 `audit_model_inputs.py`의 `feature_rule()`에서 관리한다. 새로운 열에 목적이 정의되지
않으면 중단한다. 이 분류는 초기 검토안이며 모델의 최종 입력 계약이나 고립 판단의 타당성 검증은 아니다.

## 초기 입력 검토 후보

| 특징 | 관측 내용 | 반드시 같이 볼 맥락 |
| --- | --- | --- |
| 통신_연령유동량_전월변화율 | 인접 두 달의 공통 코드·좌표에서 관측한 연령 유동량 변화 | 공통 위치 수·비율, 연령 관측률 |
| 카드1_전체_결제건수_전월변화율 | 가맹점 지역·연령별 개인 거래의 전체 건수 변화 | 전체 건수, 해석보류 비중, 계절·가격·결제수단 변화 |
| 카드1_사회활동관련후보_건수전월변화율 | 외식·카페+문화·오락+운동 후보 업종의 건수 변화 | 후보 비중, 외식 포함 여부의 민감도, 전체 소비 변화 |

세 특징의 단위는 비율이며 -0.1은 10% 감소다. 감소 원인을 고립으로 단정하지 않는다.
통신은 거주민 수·개인의 외출 횟수·고유 방문자 수가 아니고, 카드 역시 실제 대인 교류가 아니다.
전체 카드와 후보 카드 변화는 같은 출처다. 별개의 독립 증거로 두 번 가중하지 않는다.
현재 두 카드 후보 변화의 상관은 약 0.8969지만, 상관만으로 조합 방식을 결정하지 않는다.

## 결측과 관측 범위

- 숫자 특징 8개에 각각 12개 결측이 있고 모두 2025년 7월의 전월 비교 불가 값이다.
- 세 후보 모두 전월 변화 계산이 가능한 조합은 8~12월의 **60행**이다.
- 7월은 전월 변화만으로 판단할 수 없다. 0으로 대체해 ‘변화 없음’으로 해석하지 않는다.
- 첫 달 `통신_전월공통위치수=0`은 이전 달 비교 자료가 없음을 뜻하며 활동 없음이 아니다.
- 현재 미분류 금액·건수·비중 3개 열은 모두 0이다. 후보 입력에는 제외하고 신규 업종 확인을 위해 보존한다.

| 관측 품질 맥락 | 현재 범위 |
| --- | --- |
| 통신 연령 관측률 | 78.45~99.38% |
| 통신 시간 관측률 | 72.96~99.41% |
| 통신 요일 관측률 | 99.51~100% |
| 전월 공통 위치 비율 | 93.52~99.86% (첫 달 제외) |

관측률은 통신 3종 결합 위치 중 해당 자료가 있는 비율이다. 낮다고 고립 위험이 높거나
인구 대표성이 낮다고 곧바로 판정하지 않는다. 2025년 12월 춘천에서 연령·시간 관측률이
가장 낮아 위치 구성 변화의 영향을 별도 확인해야 한다. 공통 위치 비교는 일부 구성 변화를
줄이는 방식이며 인구 대표성이나 모든 관측 편향을 해결한 것은 아니다.

## 반복값과 중복 정보

지역 유동량·시간대·요일·자료별 관측률 등 **19개 지역 공통 특징**은 6개 연령에 반복된다.
실제 관측 단위 조합은 6개월×2지역인 **12개**다. 이를 연령별 정보나 72개의 독립 관측으로
다루지 않는다. `model_region_context_review.csv`는 12개 조합만 저장한다.
공통 위치 수·비율은 연령별 유효 위치로 계산하므로 정의상 연령 단위를 유지한다.

카드1·2 결제건수 전월 변화율의 피어슨 상관은 **0.9999985362**다.
카드2 변화는 초기 점수 입력에서 제외하고 교차확인용으로 남긴다. 높은 상관이 동일 거래임을
증명하는 것은 아니며, 두 출처 합계나 점수 근거를 단순 합산하지 않는다.

같은 관측 단위 안에서 절대 상관 0.95 이상인 쌍은 참고 표에 기록한다.
지역 공통값은 12개 조합으로 축소하고, 연령 특징은 해당 집계 조합으로 비교한다.
이는 탐색 경고 기준이며 자동 제거·가중치·정확도 판정 기준은 아니다.
서로 다른 관측 단위의 특징 간 상관을 같은 방식으로 혼합해 해석하지 않는다.

`data/processed/`에 다음 결과를 만들며 Git에는 올리지 않는다.

- `model_feature_review.csv`: 92개 열별 목적·근거·관측 단위·수치 범위·결측·상수 여부.
- `model_feature_missingness.csv`: 특징·월별 결측 수.
- `model_feature_correlations.csv`: 같은 관측 단위의 높은 상관 쌍.
- `model_region_context_review.csv`: 12개 지역 공통 맥락 조합.
- `model_input_review.csv`: 72개 조합의 후보 3개·품질 맥락·전월 변화 계산 가능 여부.
- `model_input_review_summary.json`: 요약·제한 사항·입력/코드 해시.

`전월변화계산가능`은 숫자가 계산 가능한지 표시한다. 신뢰도 합격이나 위험 판단 가능을 의미하지 않는다.
정제 결과가 바뀌면 공간 대조·업종 민감도·입력 검토를 필요한 순서로 다시 수행한다.

## main에서 정리할 범위와 위험도 브랜치의 작업

정제 스크립트·지역 경계 예외·업종 처리 기준·입력 검토 기록은 main에서 관리한다.
경계 대조는 원본 UTM-K를 EPSG:5179로 해석한 조건부 결과이고 대상 좌표 2개 예외를 유지한다.
전체 CRS·좌표 대표점 의미와 보류 업종 상세 정의는 제공기관 확인 사항으로 남긴다.
확인 전 검증 완료라고 표현하거나 불확실한 특징을 직접 고립 근거로 확대하지 않는다.

이 단계 커밋 후 `hyeonji/risk-model` 브랜치에서 다음을 설계한다.

1. 지역×연령 수준의 위험 신호 정의와 4축의 의미. 현재 직접 관측하지 않는 축은 근거 없이 채우지 않는다.
2. 정답 라벨 유무에 맞는 검증 방법과 외부 근거·전문가 검토 계획.
3. 7월 판단 보류, 관측 품질, 중복 카드 신호, 계절성과 집단 규모의 처리 기준.
4. 산출 방식·가중치·5단계 경계의 민감도와 판단 근거 기록.

72행은 집계 조합 수이며 72명의 개인 또는 독립 정답 표본이 아니다.
6개월 자료로 연간 계절성이나 충분한 미래 예측 성능을 검증했다고 주장하지 않는다.
