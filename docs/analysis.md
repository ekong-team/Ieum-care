# 데이터 분석 기준

범위는 제공 데이터 정제 → 활동 위축 신호 → 검토 단계 → 원인 가설 → 1차 우선 검토 순위다. 복지자원 부족에 따른2차 우선순위와 실제 프로그램 기획·평가는 별도 기능이다.

## 자료와 분석 단위

- 현재 자료: 2025년7~12월, 강남구·춘천시, 10대·20대·30대·40대·50대·60세 이상.
- 월×활동지역×연령×성별 집계다. 남녀144개와 합산72개, 총216개 분석 조합이다.
- 통신은 관측 유동량이다. 비용·고유 인원수가 아니며 카드와 동일 개인을 연결하지 않는다.
- 소비 지표는 카드1 개인 결제건수다. 법인은 제외하고 카드1·카드2를 합산하지 않는다.
- 원본 성별 코드를 male/female로 변환한다. 합산 변화율을 남녀 변화율의 평균으로 만들지 않는다.

## 정제와 비교

`scripts/data_processing/build_sex_features.py`가 성별 입력을 만든다. 월·지역·연령 코드를 통일하고 60세 이상은60GU로 유지한다. 남녀 합계가 기존 합산 건수·유동량과 일치하는지 검사한다.

카드 결제건수는 월별 일수로 나눈 일평균을 비교한다. 통신은 같은 성별·집단에서 전월과 공통으로 관측된 위치를 이용한다. 입력 중복·월 누락·관측 범위·수치 범위를 확인한다. 자료 부족을 0으로 채워 낮은 단계로 판정하지 않는다.

## 활동 위축 검토 단계

기본 감소 기준은 전월 대비3%이며,5단계의 큰 감소 기준은5%다. 연속 전월 비교2회에는 원자료3개월이 필요하다.

| 단계 | 관측 조건 |
| --- | --- |
| 1 | 두 지표 모두 기본 감소 조건에 해당하지 않음 |
| 2 | 카드 또는 통신 한 지표의 감소 |
| 3 | 카드·통신 동시 감소 |
| 4 | 동시 감소가 전월 비교2회 연속 |
| 5 | 지속 조건과 현재 두 지표5% 이상 감소, 골프·레저 제외 소비에서도 지속 조건 충족 |

이 기준은 프로젝트의 시범 규칙이다. 정답 라벨로 검증한 임상 기준이나 사회적 고립 확률이 아니다. 판정 상태는 complete(완료),partial(부분판정),held(보류)다. 부분판정의 단계는 확보된 근거의 하한이며 보류는 단계null이다.

민감도는 월합계 비교·감소 기준2%·4% 등 대체 조건에서 결과가 달라지는지 확인한다. 민감도 경고는 보존하며 기본 순위의 별도 가중치로 쓰지 않는다.

## 특성·원인 가설·외부 정보

소비와 유동량의 동반 위축, 지속 감소 등 관측 신호에서 확인할 가설을 제시한다. 각 가설은 실제 근거ID를 참조한다. 실직·우울·경제적 결핍이나 개인의 지원 욕구를 집계만으로 확정하지 않는다.

주민등록 인구와 달력은 배경 정보다. 주민 인구는 활동지역 집계와 모집단이 달라 활동량의 분모로 사용하지 않는다. 일평균은 달 길이만 조정하며 휴일·계절성을 보정한 수치가 아니다.

선택적으로 Tavily가 공식 자료 후보를 찾고 Gemini가 주어진 근거·가설·질문을 검토한다. 출처의 지역·시점·인용 적합성을 검사하며 게시판 목록을 통계표로 간주하지 않는다. 웹 수치를 자동 병합하거나 모델 의견으로 단계·순위를 바꾸지 않는다. 실제 시험에서는 채택할 새 수치·확정 인과 근거를 얻지 못했다. 기본 offline 결과와 실제 외부 호출 기록을 구분한다.

## 1차 우선 검토 순위

동일 기준월의 complete 집단을 단계 내림차순으로 정렬한다. 동일 단계는 공동 밀집순위다. 남녀24개 집단과 합산12개 집단의 순위는 별도다. 부분판정·보류는 순위 밖 별도 목록으로 보존한다. 위험도 기준의 검토 순위이며 지원 자격·지원 효과·복지자원 충분성을 뜻하지 않는다.

2025년12월 공동1순위는 춘천30대남녀·40대남성이다. 춘천30대여성은 카드 일평균−6.62%,유동량−4.57%,연속 동시 감소 비교2회로4단계다.

## 출력

| 파일 | 내용 |
| --- | --- |
| analysis_bundle.json | 전체 집단·근거·가설·특성·배경·실행 기록 |
| profiles/ | 공통 프로필 집단별 JSON |
| priority_review.json | 기준월 남녀1차 순위 |
| aggregate_priority_review.json | 별도 합산 비교 순위 |
| analysis_explained.md | 사람이 읽는 결과 설명 |
| verification.json | 원본·코드 해시와 재계산 대조 결과 |

검증기는 원본 입력으로 단계·근거·순위를 다시 계산한다. 코드 정리 뒤에는 새 실행 결과를 생성하며 과거 실행의 코드 해시를 덮어쓰지 않는다.

이전 합산 분석을 재현하는 ai/risk_model과 scripts/data_processing의 선행 도구는 현재 성별 분석 입력의 배경자료 생성에 사용된다. 현재 판정은 ai/analysis_agent/assessment.py가 담당한다.
