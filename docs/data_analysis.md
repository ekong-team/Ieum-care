# 특징 분석·업종 기준·모델 입력 검토

업종 분류와 민감도, 입력 후보의 근거를 한 문서에서 관리한다. 업종별 전체 배정은 `industry_classification.py`와 생성된 `industry_classification_review.csv`에서 확인한다.

## 업종 분류 기준

### 목적과 한계

기존 외식·카페/문화·오락/운동/미분류에서 활동 목적별 분류로 확장했다.
업종명에 근거한 팀 검토용 분류안이며, 검증된 사회적 고립 분류체계가 아니다.
의료·금융·상품 구매를 사회활동 관련 시설 이용과 구분하고 포괄 업종은 해석보류로 남긴다.
분류표에 없는 새 업종과 결측 업종은 미분류로 보존한다.
미분류가 감소해도 데이터의 의미가 모두 밝혀졌다는 뜻은 아니다.

### 공통 정의와 재생성

분류 정의는 `scripts/data_processing/industry_classification.py`에서 관리한다.
카드 전처리와 EDA가 같은 정의를 읽는다. 이 문서는 현재 v2의 검토용 스냅샷이다.
원본 업종 표기는 그대로 유지하고 각 업종을 하나의 그룹에만 배정한다.

```powershell
python scripts/data_processing/run_preprocessing.py
```

결과는 Git에서 제외된 `data/processed/`에 저장한다.
`industry_classification_review.csv`에는 관측 업종별 금액·건수·분류 근거·주의사항이 포함된다.
카드1·2 전체 합계는 출처별로 유지하고 서로 더하지 않는다.

### 사회활동 관련 후보 특징

외식·카페 + 문화·오락 + 운동의 카드1 결제건수 합계를 후보 특징으로 만든다.
혼자 이용·포장 등도 포함될 수 있어 실제 교류 횟수나 참여자 수가 아니다.
전체 결제건수(해석보류 포함)를 분모로 사용한다. 첫 달 전월 변화와 분모 0은 결측으로 남긴다.
비중 전월 차이는 -0.01이면 1%p 하락이고, 건수 전월 변화율은 -0.1이면 10% 감소다.
사회활동 관련 업종 선정은 팀 검토·민감도 분석 대상이며 현재 위험 점수나 라벨로 변환하지 않는다.

## 해석보류 처리와 민감도

### 확인한 제공 문서의 범위

`2026빅콘테스트_신한카드_데이터_레이아웃_안_20260903.xlsx`에서
카드1의 `MCT_RY_CD`는 가맹점 업종으로 정의되어 있다. 검토한 제공 파일에는
해석보류 10개 업종의 상세 거래 범위나 대면/온라인 구분 기준이 없다.
업종 이름이나 건수 규모만으로 상세 의미를 확정하지 않는다.

| 해석보류 업종 | 추가 확인이 필요한 내용 |
| --- | --- |
| ZZ_나머지 | 포함 업종 목록과 잔여 분류 기준 |
| 컴퓨터/소프트웨어 | 상품·서비스 범위와 결제 채널. 온라인 결제로 단정하지 않음 |
| 쇼핑몰·백화점·기타유통·전용매장·체인점·면세점 | 매장/채널 분류인지 상품 분류인지, 실제 취급 품목 |
| 결제대행(PG) | 실제 구매 품목·서비스와 중개 거래 범위 |
| 방문판매/다단계판매 | 판매 방식 외 구매 대상과 거래 범위 |

확인 질문은 제공기관에 “해당 업종의 포함 거래 예시, 분류 기준, 온라인/오프라인 구분 가능 여부”로 전달한다.
외부의 다른 카드사 업종표를 그대로 적용하지 않는다.

### 현재 적용 기준

- 해석보류와 미분류 거래는 원래 금액·건수 및 전체 합계에 보존한다.
- 사회활동 관련 후보의 분자는 외식·카페, 문화·오락, 운동만 사용한다.
- 후보 비중의 분모는 해석보류·미분류를 포함한 전체 카드1 결제건수다.
- 상세 정의가 없는 업종을 후보 분자로 이동시키지 않는다. 미분류가 0이어도 의미 검증이 완료된 것은 아니다.
- 원본 업종 분류 v2와 `card_features.csv`, `risk_features.csv`는 변경하지 않는다.

이는 정제와 탐색을 위한 처리 기준이다. 실제 교류 여부나 고립 위험의 판단 기준으로
검증됐다는 뜻은 아니다. 데이터는 가맹점 지역별 개인 카드 거래 집계이며
거주민만의 활동이나 같은 개인의 통신·카드 추적 자료가 아니다.

### 재현 방법과 비교 가정

```powershell
.venv\Scripts\python.exe scripts/data_processing/analyze_features.py --only industry
.venv\Scripts\python.exe scripts/data_processing/validate_processed.py
.venv\Scripts\python.exe -m unittest discover -s tests -v
```

통합 정제는 이 민감도 분석까지 자동 실행한다. 민감도만 갱신할 때 위 명령을 사용한다. 원본 합계, 분류 버전,
기존 후보 특징과의 일치 여부를 먼저 검사하고 입력·코드 해시를 기록한다.

| 비교안 | 분자 | 분모 | 용도 |
| --- | --- | --- | --- |
| 현재기준 | 외식·카페+문화·오락+운동 | 전체 | 기존 특징 재현 |
| 보류제외분모 | 현재 후보 | 전체-해석보류-미분류 | 분모 축소의 영향 |
| 보류전체후보포함 | 현재 후보+해석보류+미분류 | 전체 | 극단 가정의 영향. 채택하지 않음 |
| 외식제외후보 | 문화·오락+운동 | 전체 | 후보 업종 선택의 영향 |

모든 계산은 월×지역×연령 72개 조합에 대해 수행한다. 전월 변화는 인접한 달만 비교하며,
7월의 전월 값과 분모가 0인 비율은 결측으로 보존한다.
비중·변화율 결과는 비율 단위다. 0.01 비중 차이는 1%p, 변화율 0.1은 10% 증가다.
서로 반대인 증가/감소 방향만 반전으로 세며, 결측 및 수치 오차는 제외한다.

생성 결과는 Git에서 제외된 `data/processed/`에 보관한다.

- `industry_held_review.csv`: 해석보류 업종별 전체 대비 금액·건수 비중.
- `industry_interpretation_coverage.csv`: 월×지역×연령별 해석보류·미분류 비중.
- `industry_sensitivity_features.csv`: 네 가정의 후보 건수·비중·전월 변화.
- `industry_sensitivity_comparison.csv`: 최대 차이와 변화 방향 반전 수.
- `industry_sensitivity_summary.json`: 요약·처리 기준·입력/코드 해시.

### 2026-10-11 결과

해석보류는 카드1 개인 결제건수의 **34.7559%**, 금액의 **31.2324%**다.
월×지역×연령별 건수 비중은 **2.1925~42.2291%**로 차이가 크며, 미분류 건수는 0이다.

| 가정 | 현재 대비 최대 후보 비중 차이 | 건수 전월 변화 방향 반전 | 비중 전월 변화 방향 반전 |
| --- | ---: | ---: | ---: |
| 보류제외분모 | 16.8861%p | 0/60 | 10/60 |
| 보류전체후보포함 | 42.2291%p | 12/60 | 21/60 |
| 외식제외후보 | 31.6477%p | 9/60 | 10/60 |

분모에서 보류 업종만 빼도 후보 건수 변화는 그대로지만 비중 변화 방향이 10개 조합에서 뒤집힌다.
그러므로 비중 하락을 곧바로 활동량 감소라고 해석하지 않는다. 후보 건수의 변화와
전체 건수의 변화, 해석보류 비중을 함께 확인한다.
외식 포함 여부에 따라서도 후보 변화 방향이 달라지므로 후보 합계 하나만으로
사회적 고립을 판단할 수 없다.

현재 전체 분모 유지 기준을 계속 적용한다. 해석보류 비중은 모델 검토용 데이터 품질 맥락이며
해석보류 비중이 높다는 이유로 위험 점수를 높이지 않는다.
상세 업종 정의와 사회활동 관련성을 확인하기 전 후보 업종 확대는 보류한다.
이 분석은 가정에 따른 특징의 안정성을 확인한 것이며 고립 분류 정확도 검증은 아니다.

## 모델 입력 검토

### 검토 범위와 결과

2026-10-11 현재 `risk_features.csv`는 2025년 7~12월×2지역×6연령의 **72행·92열**이다.
점수·등급·개인 라벨은 없고, 이 문서는 위험도 개발 전 탐색 후보를 정리한다.
특징을 삭제하거나 결측을 대체하거나 학습·표준화하지 않는다.

| 사용 목적 | 열 수 | 처리 |
| --- | ---: | --- |
| 식별키 | 3 | 월·지역·연령. 결합·보고 및 시간 순서에 사용 |
| 입력 검토 후보 | 3 | 활동량 변화 후보. 방향·가중치·유효성은 위험도 브랜치에서 검토 |

| 카드1_전체_결제건수_전월변화율 | 가맹점 지역·연령별 개인 거래의 전체 건수 변화 | 전체 건수, 해석보류 비중, 계절·가격·결제수단 변화 |
| 카드1_사회활동관련후보_건수전월변화율 | 외식·카페+문화·오락+운동 후보 업종의 건수 변화 | 후보 비중, 외식 포함 여부의 민감도, 전체 소비 변화 |

세 특징의 단위는 비율이며 -0.1은 10% 감소다. 감소 원인을 고립으로 단정하지 않는다.
통신은 거주민 수·개인의 외출 횟수·고유 방문자 수가 아니고, 카드 역시 실제 대인 교류가 아니다.
전체 카드와 후보 카드 변화는 같은 출처다. 별개의 독립 증거로 두 번 가중하지 않는다.
현재 두 카드 후보 변화의 상관은 약 0.8969지만, 상관만으로 조합 방식을 결정하지 않는다.

### 결측과 관측 범위

- 숫자 특징 8개에 각각 12개 결측이 있고 모두 2025년 7월의 전월 비교 불가 값이다.
- 세 후보 모두 전월 변화 계산이 가능한 조합은 8~12월의 **60행**이다.
- 7월은 전월 변화만으로 판단할 수 없다. 0으로 대체해 ‘변화 없음’으로 해석하지 않는다.
- 첫 달 `통신_전월공통위치수=0`은 이전 달 비교 자료가 없음을 뜻하며 활동 없음이 아니다.
- 현재 미분류 금액·건수·비중 3개 열은 모두 0이다. 후보 입력에는 제외하고 신규 업종 확인을 위해 보존한다.

| 관측 품질 맥락 | 현재 범위 |
| --- | --- |
| 통신 연령 관측률 | 78.45~99.38% |
| 통신 시간 관측률 | 72.96~99.41% |
| 통신 요일 관측률 | 99.51~100% |
| 전월 공통 위치 비율 | 93.52~99.86% (첫 달 제외) |

관측률은 통신 3종 결합 위치 중 해당 자료가 있는 비율이다. 낮다고 고립 위험이 높거나
인구 대표성이 낮다고 곧바로 판정하지 않는다. 2025년 12월 춘천에서 연령·시간 관측률이
가장 낮아 위치 구성 변화의 영향을 별도 확인해야 한다. 공통 위치 비교는 일부 구성 변화를
줄이는 방식이며 인구 대표성이나 모든 관측 편향을 해결한 것은 아니다.

### 반복값과 중복 정보

지역 유동량·시간대·요일·자료별 관측률 등 **19개 지역 공통 특징**은 6개 연령에 반복된다.
실제 관측 단위 조합은 6개월×2지역인 **12개**다. 이를 연령별 정보나 72개의 독립 관측으로
다루지 않는다. `model_region_context_review.csv`는 12개 조합만 저장한다.
공통 위치 수·비율은 연령별 유효 위치로 계산하므로 정의상 연령 단위를 유지한다.

카드1·2 결제건수 전월 변화율의 피어슨 상관은 **0.9999985362**다.
카드2 변화는 초기 점수 입력에서 제외하고 교차확인용으로 남긴다. 높은 상관이 동일 거래임을
증명하는 것은 아니며, 두 출처 합계나 점수 근거를 단순 합산하지 않는다.

같은 관측 단위 안에서 절대 상관 0.95 이상인 쌍은 참고 표에 기록한다.
지역 공통값은 12개 조합으로 축소하고, 연령 특징은 해당 집계 조합으로 비교한다.
이는 탐색 경고 기준이며 자동 제거·가중치·정확도 판정 기준은 아니다.
서로 다른 관측 단위의 특징 간 상관을 같은 방식으로 혼합해 해석하지 않는다.

### main에서 정리할 범위와 위험도 브랜치의 작업

정제 스크립트·지역 경계 예외·업종 처리 기준·입력 검토 기록은 main에서 관리한다.
경계 대조는 원본 UTM-K를 EPSG:5179로 해석한 조건부 결과이고 대상 좌표 2개 예외를 유지한다.
전체 CRS·좌표 대표점 의미와 보류 업종 상세 정의는 제공기관 확인 사항으로 남긴다.
확인 전 검증 완료라고 표현하거나 불확실한 특징을 직접 고립 근거로 확대하지 않는다.

이 단계 커밋 후 `hyeonji/risk-model` 브랜치에서 다음을 설계한다.

후속 구현인 팀 규칙 기반 5단계 v1의 현재 상태는 [위험 신호 설계](risk_model_design.md)에 기록한다.
아래는 정제 단계에서 정리한 설계 과제이며, 별도 4축 점수는 v1에 추가하지 않았다.

1. 지역×연령 수준의 위험 신호 정의와 4축의 의미. 현재 직접 관측하지 않는 축은 근거 없이 채우지 않는다.
2. 정답 라벨 유무에 맞는 검증 방법과 외부 근거·전문가 검토 계획.
3. 7월 판단 보류, 관측 품질, 중복 카드 신호, 계절성과 집단 규모의 처리 기준.
4. 산출 방식·가중치·5단계 경계의 민감도와 판단 근거 기록.

72행은 집계 조합 수이며 72명의 개인 또는 독립 정답 표본이 아니다.
6개월 자료로 연간 계절성이나 충분한 미래 예측 성능을 검증했다고 주장하지 않는다.
