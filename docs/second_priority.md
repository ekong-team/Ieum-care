# 2차 우선순위와 상위 오케스트레이터

작성: 김정욱 · 작성일: 2026-10-23 · 코드: `ai/orchestrator/` · 상태: **팀 합의 전 규칙 초안**

공고의 운영 흐름 마지막 단계 "우선 지원 대상 지역·계층 도출"을 맡는다.
1차 순위(분석 Agent, 위험 단계)를 바꾸지 않고, 같은 1차 순위 안에서만 기존 자원으로 대응하기 어려운 집단을 앞에 둔다.
화면의 2차 검토표(`welfare-cohort-review-0.1`)가 비워 둔 `second_priority_rank`를 채우는 기준이다.

## 1. 흐름

```
① 분석 결과 읽기 (data/processed/analysis_current/latest.json, 다시 계산하지 않음)
② 1차 순위 (분석 묶음에 있음, 위험 단계 공동 밀집순위)
③ 복지 결과 모으기: 화면에서 내려받은 review JSON(live 결과 재사용) 또는 저장 자료(offline) 조회
④ 2차 순위 (규칙, LLM 없음)
⑤ 기획 대상 선택: 2차 순서대로 G2·G3 집단 상위 N개(기본 3)
⑥ 집단별 기획 그래프: 원인은 분석 Agent 결과, 복지는 ③의 결과를 그대로 사용 (다시 조회하지 않음)
⑦ 리포트 (orchestrator-report-0.1, status=needs_human_review)
```

오케스트레이터는 분기·루프가 없는 순차 흐름이라 함수로 구현했다. 루프는 각 에이전트 안에 있다(분석 재검색, 기획↔평가 재기획).
오케스트레이터가 live 복지 추천을 직접 부르지 않는 이유: 24개 집단 × (검색 2회 + Gemini 1회)는 무료 한도를 넘는다.

## 2. 공백 등급

| 등급 | 조건 | 대응 경로 |
| --- | --- | --- |
| G3 공백 | 조회 성공, 연령이 맞는 후보(age_match ≠ none)가 없음 | 신규 기획 우선 |
| G2 부분 공백 | 후보는 있지만 '연령이 확인된(overlap) 직접 연결 자원'이 없음 | 기존 자원 연계 + 보완 기획 |
| G1 자원 확보 | 연령이 확인된 직접 연결 자원이 1개 이상 | 기존 자원 연계 우선 (기획하지 않음) |
| 보류 | 조회 실패·미조회 | 순위 밖. 자원이 없다고 보지 않는다 |

직접 연결 자원: live는 AI 연관성 분류 `direct`, offline은 지원 목적 `connection` (둘 다 있으면 AI 분류 우선).
후보 '수'는 공급량·정원이 아니므로 쓰지 않는다. 있나 없나만 본다.

## 3. 정렬

1. 1차 순위 오름차순 (위험이 높은 집단이 먼저)
2. 같은 1차 순위 안에서 G3 → G2 → G1
3. 1차 순위와 등급이 모두 같으면 공동 순위 (1차와 같은 밀집 순위)

공백이 커도 1차 순위가 낮은 집단은 1차 순위가 높은 집단보다 앞서지 않는다.
대안(가중 점수, 공백 우선)은 가중치 근거를 설명할 수 없거나 '위험 수준에 따라'라는 공고 취지와 어긋나 택하지 않았다.

## 4. 실행

```bash
python -m ai.orchestrator.run                         # 저장 자료로 끝까지
python -m ai.orchestrator.run --review 검토표.json    # 화면 일괄 추천(live) 결과 재사용
```

다른 분석 배치의 검토표는 거부한다. 검토표에 없는 집단은 미조회(보류)로 둔다.
한 집단의 기획이 실패해도 나머지 집단과 리포트는 남는다.

## 5. 실제 데이터 적용 (2026-10-23, offline, 2025-12 기준 24집단)

| 2차 | 1차 | 단계 | 집단 | 등급 |
| --- | --- | --- | --- | --- |
| 1 | 1 | L4 | 춘천 30대 남·여, 40대 남 | G1 (고독사 예방 사업) |
| 2 | 2 | L3 | 춘천 10대 남·여, 60대 남·여 | G2 |
| 3 | 2 | L3 | 춘천 20대 남·여, 40대 여, 50대 여 | G1 |
| 4 | 3 | L2 | 강남 20대 남, 30대 남·여 | G2 |
| 5 | 3 | L2 | 춘천 50대 남 | G1 |
| 6 | 4 | L1 | 강남 나머지 9개 | G2 |

기획 대상: 춘천 10대 여·남, 60대 이상 여 (60대 이상 남은 같은 2위라 동률 기획 대기).

## 6. 열린 결정과 한계

- **1차 최상위(L4) 집단이 G1이면 기획 대상에서 빠진다.** 위 결과의 G1은 저장 자료 6개 중 '고독사 예방 사업'(19~64세) 하나로 정해진 것이라,
  live 추천 결과로 다시 확인한 뒤 '최상위 순위는 G1이어도 보완 기획'을 넣을지 정한다.
- 저장 자료가 작아 G3가 나오지 않는다. 의미 있는 2차 순위는 live 추천 결과(review JSON)가 필요하다.
- 공백 판정 로직이 기획 그래프의 공백 분석(`ai/nodes/gaps.py`)과 같은 기준을 따로 갖고 있다. 두 브랜치가 병합되면 하나로 합친다.
- 규칙은 팀 합의 전 초안이다. 결과는 지원 자격·효과·실제 자원 부족을 확정하지 않으며 모든 항목에 담당자 확인이 필요하다.
