## 구현한 보완

`ai/risk_model/build_activity_evidence.py`는 기존 v1 단계를 바꾸지 않고 설명 근거를 추가한다.

- 소비 일평균을 직전 인접 3개월 평균과 비교. 현재·미래 월은 기준에 포함하지 않는다. 3개월은 팀의 분석 가정으로 논문의 검증된 기간이 아니다.
- 지역 전체 결제건수 합산의 일평균 변화와 연령별 변화를 비교한다. 상대 차이는 계절 보정이나 인구당 활동량이 아니다.
- 외식·카페/문화·오락/운동 세 후보 그룹의 동반 감소 수를 0·2·3·5% 가정에서 표시한다. 후보 선택·감소 기준은 검증되지 않았으며 사회적 만남의 수를 측정하지 않는다.
- 기존 이동·소비 동시감소 지속 기간, 관측률, 업종 제외 민감도와 보류 이유를 Agent 입력으로 보존한다.
- 입력 해시와 코드 해시로 결과 재현 상태를 기록한다.

실행: `python ai/risk_model/build_activity_evidence.py`

결과는 로컬 `data/processed/activity_evidence.csv`, `agent_activity_evidence.json`, `activity_evidence_manifest.json`. 72개 집단-월에 적용, 직전 3개월이 있는 10~12월 36개 행에서 기준 비교 가능. 7~9월의 기준 결측을 0으로 채우지 않는다. 신규 테스트는 미래 정보 배제·월 누락·0 분모·연도 경계 확인.

12월 춘천 30대 소비는 직전 3개월 대비 -9.26%, 40대 -7.86%. 전월 소비 변화의 춘천 전체 대비 차이는 각각 +0.74%p, -0.05%p. 후보 세 그룹 모두 전월 3% 이상 감소하지만 지역 공통 감소라는 대안 설명을 같이 제시한다.

## 아직 해결하지 못한 부분

- 관계 수·연락 빈도·사회적 지지·외로움의 실제 정답 자료 없음. 집단 수준 기술 분석이며 개인 예측 성능은 주장하지 않는다.
- 6개월로 연간 계절성이나 만성 고립을 식별할 수 없다. 통신 공통 위치 기반 전월비를 raw 유동량의 장기 비교와 혼동하지 않는다.
- 3/5%·2개월·관측률 임계값은 v1 운영 가정. 문헌에서 검증된 기준이라는 표현 금지. 근거 없이 새로운 점수를 가산하지 않는다.
- 실제 접근성을 계산하려면 공통 공간 경계·좌표계·시설 유형·운행 정보의 확인이 필요하다.
- 외부 지역 여건은 거주민 자료일 수 있어 가맹점/유동 지역 자료의 인구당 분모로 바로 쓰지 않는다. 두 지역 정적 변수로 72개의 독립 예측 표본을 만들 수 없다.

## 후속 검증

실제 고립 확인은 대상 집단에 적합한 관계망·사회적 지지·외로움 평가 자료와 별도 비교한다. 해당 자료가 없으면 시범 규칙의 민감도·자료 품질·설명 일관성만 보고한다. 앞으로 월별 검증 시 기준은 과거 정보로 고정하고 다음 월에서 평가한다. 공공 지역 평균을 개인 정답 라벨로 사용하지 않는다.

## 2026-10-14 공간 검증 상태 갱신

사용자 제공 SGIS 경계 ZIP으로 로컬 재현을 완료했다. 아래의 이전 기록 중 경계 미보유·공간 재현 대기는 이 갱신으로 대체한다. 대상 위치 126,291개 중 2개 불일치이며, 제외 전후 2%·3%·5% 감소 기준 모두 단계 변화가 없다. 좌표계·대표점의 기관 정의 확인은 남아 있어 조건부 결과로 전달한다. 전체 테스트 22개 통과. 상세 기록: `docs/spatial_revalidation_20261014.md`. 팀 공동 검토는 별도로 필요하다.
