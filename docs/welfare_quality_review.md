# 복지자원 추천 품질 검증

이 검증은 실제 추천의 적합성과 근거를 사례별로 확인한다. 개인의 복지 자격이나 고립 예방 효과를 입증하지 않는다. 사례 4개는 목적을 전체로 통일하고 실제 완료 판정의 지역·연령·성별·위험도·원인 맥락을 보존한다.

| 순서 | 사례 ID | 집단 | 중점 확인 |
| --- | --- | --- | --- |
| 1 | CC30F | 춘천시·30대·여성 | 추가 자격·상세 출처 |
| 2 | CC60M | 춘천시·60대 이상·남성 | 만 65세 이상과 집단 구간 구분 |
| 3 | GN20F | 강남구·20대·여성 | 지역·청년 조건 |
| 4 | GN10M | 강남구·10대·남성 | 성인 사업 혼입·10~19세 구간 |

## 실행·보관

```powershell
# 기본 동작은 입력과 빈 검증표만 준비한다. 외부 API 호출 없음.
python scripts/integration/validate_welfare_quality.py --case CC30F
# 같은 사례의 실제 Tavily·Gemini 추천 한 번. 다른 사례는 실행하지 않는다.
python scripts/integration/validate_welfare_quality.py --case CC30F --allow-external
```

생성 경로: `data/processed/welfare_quality/<사례>/<분석 배치 앞16자>/attempt-01/`. 원래 입력·분석 배치·1차 순위는 request.json, 추천 원문은 result.json, 상태·시각·외부 호출 횟수는 manifest.json, 원문 대조표는 review.csv다. Git 제외 경로이며 키·원본 개인 데이터는 보관하지 않는다. 기본 캐시가 유효하면 검색을 재사용할 수 있으며 실제 요청 직전 콜백으로 API 호출을 센다. 시도 번호가 같은 완료·오류·진행 흔적은 재실행하지 않는다. 추가 실행이 필요하면 사용자 판단 후 새 `--attempt` 번호로 명시한다. 오류 시 재시도·모델 변경·다른 자료로 대체하지 않는다.

## 후보별 원문 대조

공식 상세 안내를 열어 ①출처 수준 ②지역·연령 ③추가 자격의 조건부 표현 ④연도·종료·모집 상태 ⑤원문에 근거한 추천 이유와 고립 예방 연관성을 확인한다. 현재 확인이 안 되는 모집·자격은 unknown으로 기록하며 적합하다고 추정하지 않는다.

review.csv의 verdict는 `pass`(원문과 맞음), `needs_confirmation`(확인 필요), `fail`(원문과 명확히 다름), `pending`(미검토)로 기록한다. evidence에는 짧은 근거와 원문 위치, note에는 한계·수정 과제를 적는다. 최종 후보 평가는 ‘적절한 검토 후보 / 추가 확인 필요 / 부적절한 추천’ 중 하나로 별도 검토 기록에 남긴다. 단순 실패 항목 수로 자동 최종 점수를 만들지 않는다. 정상 0개도 검색 누락 여부를 확인하며 실제 서비스 부재로 확정하지 않는다.

한 집단의 문제를 확인한 후 나머지 사례로 확대한다. 소수 사례로 정확도·재현율·실제 예방 효과의 전체 성능을 주장하지 않는다.

## 2026-10-23: 첫 사례 CC30F 검토 결과

실제 완료 판정의 춘천시·30대·여성, 기준월2025-12·4단계·1차1순위를 사용했다. 분석 배치는 `63a0e71b0b25cb71…`다. Tavily2회·Gemini1회, 검색 응답 크레딧2, 추천 후보1개였다. 다른3사례는 실행하지 않았다. 원래 입력·추천 원문은 Git 제외 폴더에 보관하고 결과 내용을 사후 교정하지 않았다.

후보는 ‘한부모가족 자녀 대학신입생 생활자립금’이며 경제 지원·고립 예방 간접 연관으로 분류됐다. 개인 자격·연령 범위·현재 운영은 미확정으로 표시했다. 다만 현재 표시 내용에는 중요한 오류가 있어 **표시 수정 전에는 부적절한 추천**으로 판정했다. 해당 사업 자체가 모든30대 여성에게 부적합하다고 단정한 판정은 아니다.

| 항목 | 판정 | 대조 결과 |
| --- | --- | --- |
| 공식 상세 출처 | fail | 추천 URL은 시청 첫 화면이다. 같은 사업의 별도 동 행정복지센터 상세 안내가 존재한다. |
| 지역·연령 | needs_confirmation | 춘천 지역 사업이나 대학 신입생 자녀·가구 상황이 필요하다. 30대 여성 개인의 자격을 확인한 것은 아니다. |
| 추가 자격 | needs_confirmation | 한부모·대학 신입생 조건은 명시했지만 별도 공식 상세 안내의 기준 중위소득65% 이하 조건이 후보 설명에 없다. 조건 충족을 확정하지 않은 점은 적절하다. |
| 현행 운영 | needs_confirmation | 2026년 사업·예산 소진 시 마감은 공식 안내와 맞지만 실제 잔여예산·접수 여부는 확인하지 못했다. |
| 내용·연관성 | fail | 추천 금액 `1,70,000원`은 공식 `1,700,000원`과 다르다. 간접 연관·직접 교류 근거 부족으로 표시한 것은 적절하다. |

원문: [추천에 사용된 춘천시청 첫 화면](https://www.chuncheon.go.kr/cityhall/), [후평1동 상세 안내](https://www.chuncheon.go.kr/village/hupyeong1-dong/news/village/?bbsId=BBSMSTR_000000000200&flag=view&nttId=15092). 상세 안내에서 금액1,700천원·중위소득65% 이하·대학 신입생 자녀 등 조건을 교차 확인했다. 근거 요약과 URL은 로컬 `source_review.json`, 항목별 판정은 `review.csv`, 최종 판정·수정 과제는 `quality_review.json`에 기록했다. 별도 검색으로 찾은 상세 출처를 원래 Agent가 찾은 출처처럼 기록하지 않는다.

검색 단계 기록은 지역8개·중앙8개 모두 상세 단서0개였다. 최종 모델 입력 출처는8개이고 모두 춘천 도메인이었다. 코드 확인 결과, 단서·종류가 같을 때 지역 출처를 앞에 정렬하여 최종8개가 지역 결과로 채워질 수 있다. 이는 이번 사례의 보완 검색 결과 활용·상세 자료 확보를 개선해야 한다는 근거이며, 모든 지역·연령의 검색 품질을 측정한 결과는 아니다.
