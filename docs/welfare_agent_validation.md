검증일: 2026-10-17. 대상: Tavily 기본 검색 + Gemini 3.5 Flash-Lite, 위험도 미연결 일반 조회.

**현재 판정: 기본 연결은 확인했으나 추천 품질 검증은 미완료다.** 실제 결과에서 검색 범위·자료 연도·지원 조건 설명의 보완 사항을 찾았다. 아래는 수정 전 `llm-grounding-0.2` 결과다. 이후 보완한 `0.3`의 실제 추천 품질을 통과 처리하지 않는다.

실행 스냅샷은 Git 제외 경로 `data/processed/welfare_validation/live_review_2026-10-17.json`에 보관했다. 검색 내용·입력 조건·처리 결과와 오류를 포함하며, 추적 링크의 불필요한 쿼리는 제거했다. 이 문서는 팀 공유용이고 스냅샷은 필요 시 별도 공유한다. 실시간 검색과 LLM 결과는 시점에 따라 달라져 동일 후보 재현을 보장하지 않는다.

## 검색 범위의 한계

GN20 검색에는 어르신 정책, 오래된 종합 복지자료집·백서·소식지와 추적용 링크가 섞였다. 현재의 긴 단일 검색어와 최대 8개 발췌문만으로 지역·연령에 맞는 서비스 상세 안내를 충분히 확보했다고 볼 수 없다. 빈 추천은 서비스 부재나 지원 불필요의 근거가 아니다.

예를 들어 [강남구보건소의 심리상담 안내](https://health.gangnam.go.kr/web/business/mental/mind/sub01.do)는 정서적 어려움과 증빙 조건을 안내한다. 이번 GN20 검색이 이 안내를 확보하지 못했다는 점은 검색 누락의 사례이며, 해당 서비스를 모든 20대에게 추천해야 한다는 뜻은 아니다. 다른 조건과 소득·진단 등 개인 상태를 추정하지 않는다.

## 이번에 보완한 항목

- 발행·게시 연도와 적용 기준 연도를 별도 종류로 전달·표시한다. 발행 연도로 현행 자격을 보증하지 않는다.
- 지원 기관과 운영 기관을 구분하고, 한 해 일정의 연례 일반화와 회원비·활동비 누락을 피하도록 AI 지시를 보완했다. 내용 오류를 서버가 모두 자동 판정할 수 있는 것은 아니다.
- 추적용 `tms.bokjiro.go.kr` 주소를 서비스 원문 출처에서 제외했다.
- 제외 건수만 남기던 응답에 `exclusion_counts`를 추가했다. 이후 조회는 검색 출처·지역·연령·지원 목적·종료·중복별 사유를 확인할 수 있다. 과거 GN20의 사유를 소급 추정하지 않는다.

보완 사항은 가짜 검색·AI 응답 테스트로 확인한다. 실서비스 추천의 정확도·재현율·예방 효과를 측정한 점수는 산출하지 않는다.

## 다음 검증 순서

1. 검색어를 짧게 만들고 지역·연령에 맞는 서비스 상세 안내를 우선 확보하는 방식을 개선한다. 고정 프로그램 목록으로 대체하지 않고 무료 검색 호출 상한을 정한다.
2. 503이 안정된 후 위 4개 조건을 다시 확인한다. 운영 주체·비용·연도 종류와 제외 사유를 실제 원문에 대조한다.
3. 위험도 담당자의 실제 출력 샘플을 받은 뒤, 위험도 없음·정상 입력·보류 입력을 비교한다. 가상 입력은 명확히 표시한다.
4. 위 검토 후 프로그램 기획 담당자와 전달 JSON을 확정한다.

조건별 화면 조회로 검토할 수 있다. 자동 회귀 검사는 프로젝트 루트에서 아래 명령으로 실행하며 외부 API를 호출하지 않는다.
