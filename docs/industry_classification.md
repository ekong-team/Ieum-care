# 카드 업종 분류 v2

## 목적과 한계

기존 외식·카페/문화·오락/운동/미분류에서 활동 목적별 분류로 확장했다.
업종명에 근거한 팀 검토용 분류안이며, 검증된 사회적 고립 분류체계가 아니다.
의료·금융·상품 구매를 사회활동 관련 시설 이용과 구분하고 포괄 업종은 해석보류로 남긴다.
분류표에 없는 새 업종과 결측 업종은 미분류로 보존한다.
미분류가 감소해도 데이터의 의미가 모두 밝혀졌다는 뜻은 아니다.

## 공통 정의와 재생성

분류 정의는 `scripts/data_processing/industry_classification.py`에서 관리한다.
카드 전처리와 EDA가 같은 정의를 읽는다. 이 문서는 현재 v2의 검토용 스냅샷이다.
원본 업종 표기는 그대로 유지하고 각 업종을 하나의 그룹에만 배정한다.

```powershell
python scripts/data_processing/build_card_features.py
python scripts/data_processing/build_risk_features.py
python scripts/data_processing/analyze_risk_features.py
```

결과는 Git에서 제외된 `data/processed/`에 저장한다.
`industry_classification_review.csv`에는 관측 업종별 금액·건수·분류 근거·주의사항이 포함된다.
카드1·2 전체 합계는 출처별로 유지하고 서로 더하지 않는다.

## 사회활동 관련 후보 특징

외식·카페 + 문화·오락 + 운동의 카드1 결제건수 합계를 후보 특징으로 만든다.
혼자 이용·포장 등도 포함될 수 있어 실제 교류 횟수나 참여자 수가 아니다.
전체 결제건수(해석보류 포함)를 분모로 사용한다. 첫 달 전월 변화와 분모 0은 결측으로 남긴다.
비중 전월 차이는 -0.01이면 1%p 하락이고, 건수 전월 변화율은 -0.1이면 10% 감소다.
사회활동 관련 업종 선정은 팀 검토·민감도 분석 대상이며 현재 위험 점수나 라벨로 변환하지 않는다.

## 그룹별 근거

| 그룹 | 해석 역할 | 분류 근거 | 주의사항 |
| --- | --- | --- | --- |
| 외식·카페 | 사회활동관련_후보 | 식사·음료·간식 관련 업종 | 혼자 이용·포장·배달 가능. 대인 교류를 직접 측정하지 않음 |
| 문화·오락 | 사회활동관련_후보 | 문화 관람·오락 시설 이용 업종 | 혼자 이용 가능하며 유료 활동 선호와 가격의 영향이 있음 |
| 운동 | 사회활동관련_후보 | 운동 시설 이용 업종 | 시설 결제가 참여 빈도·동행 여부를 나타내지 않음 |
| 식료품·일상구매 | 생활소비_맥락 | 식료품 및 일상 구매 업종 | 복합 매장은 비식품도 판매. 구매 감소는 소득·결제수단 변화로도 설명 가능 |
| 생활용품 | 생활소비_맥락 | 생활·주거·취미 물품 구매 업종 | 물품 구매가 해당 활동의 참여나 교류를 뜻하지 않음 |
| 의류·잡화 | 생활소비_맥락 | 의류·패션·미용 물품 구매 업종 | 비필수 지출·가격 차이를 고립 위험으로 직접 사용하지 않음 |
| 의료·건강 | 의료이용_맥락 | 사람의 의료·약품·보건 서비스 업종 | 의료 이용량으로 건강상태·고립 여부를 판정하지 않음. 기타의료는 세부 범위 확인 필요 |
| 교통·차량 | 이동소비_맥락 | 교통수단·차량 구매 및 유지 관련 업종 | 차량 구매·주유·정비는 이동 횟수와 다름 |
| 교육 | 교육지출_맥락 | 교육기관·학습 공간 이용 업종 | 학습지·등록금은 대면 참여를 보장하지 않으며 결제자가 학습자와 다를 수 있음 |
| 문화·운동용품 | 물품구매_맥락 | 책·문화·운동 관련 물품 구매 업종 | 시설 이용과 구분. 물품 구매로 사회적 참여를 추정하지 않음 |
| 생활서비스 | 서비스이용_맥락 | 미용·세탁·목욕 등 생활 서비스 업종 | 일부 대면 서비스 가능성이 있으나 관계망 형성의 증거는 아님 |
| 금융·공과금 | 위험지표_제외후보 | 보험·세금·통신료·상품권/복권 등 지출 | 납부·금융성 거래와 생활 활동을 구분. 상품권/복권은 복합 항목 |
| 숙박·여행 | 여행지출_맥락 | 숙박·여행 서비스 업종 | 관광·출장·일회성 결제 영향. 거주민 활동이나 고립의 직접 지표가 아님 |
| 기타서비스 | 위험지표_제외후보 | 전문·반려동물·행사·부동산 등 서비스 업종 | 이질적이고 일회성인 지출. 고립 신호 산출에 일괄 포함하지 않음 |
| 유흥 | 위험지표_제외후보 | 유흥 업종을 다른 문화·운동 활동과 분리 | 이용 여부로 사회적 관계나 도덕적 평가를 추정하지 않음 |
| 해석보류 | 해석보류 | 상품·채널·포괄 업종만으로 활동 목적을 특정하기 어려움 | 세부 정의/거래 범위 확인 전 사회활동 점수에서 제외 |

## 다음 검증 과제

- 포괄 업종의 세부 정의와 거래 범위를 원본 제공 문서로 확인한다.
- 후보 업종 포함/제외를 바꾸었을 때 지역·연령별 결과가 얼마나 달라지는지 비교한다.
- 업종 구매의 변화와 고립 위험의 관계는 외부 근거·전문가 검토로 확인한다.
- 4축 점수와 5단계 분류 기준은 이 검토 후 설계한다.
